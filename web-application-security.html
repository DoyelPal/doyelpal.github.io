Web & Application Security

Explore common web vulnerabilities, secure coding techniques, and defensive testing. Start with the learning objectives and security fundamentals, then select a module for focused lessons, examples, hands-on activities, and practice questions.

Learning Objectives

  • Identify common web application vulnerabilities and explain their impact on confidentiality, integrity, and availability.
  • Explain the causes and prevention of injection attacks, cross-site scripting (XSS), and cross-site request forgery (CSRF).
  • Apply secure input handling, output encoding, authentication, and access control practices.
  • Recognize risks in sessions, APIs, file uploads, and security configuration.
  • Use authorized, defensive testing techniques to discover, document, and remediate vulnerabilities.

Web & Application Security Fundamentals

Build a foundation for understanding vulnerabilities, secure development, and responsible security testing.

Attack Surface

Web forms, URLs, cookies, APIs, file uploads, and third-party components can expose application functionality to untrusted input.

Trust Boundaries

Treat client-side input as untrusted. Enforce authorization, validation, and security controls on the server.

Secure Coding

Use parameterized queries, context-aware output encoding, least privilege, safe session handling, and secure defaults.

Defensive Testing

Combine code review, security test cases, dependency checks, and authorized application testing to find and fix weaknesses.
