Compare two simplified C code samples. Assume input is a valid null-terminated string. Which version prevents an out-of-bounds write into name?

Code A
char name[8];

No destination size check.

Code B
char name[8];
snprintf(name,
  sizeof name,
  "%s", input);

Limits writes to the destination capacity (may truncate input).

CHALLENGE 4 · 15 XP

🔎 Real-world connection: PHP2Shell

PHP2Shell is the nickname used for two critical October 2026 PHP runtime memory-safety vulnerabilities, CVE-2026-109618 and CVE-2026-109619. Neither is a textbook stack-based buffer overflow. Compare the failure mechanisms rather than treating them as the same exploit.

Buffer overflow

Writes beyond the bounds of an allocated buffer, potentially corrupting adjacent memory.

PHP2Shell memory bugs

Problems involving invalid memory state, including uninitialized-memory and use-after-free behavior.

Fictional SOC alert:
14:01 POST /form.php size=900000
14:02 PHP worker memory error
14:03 PHP worker crashed
14:04 Unexpected shell child process

A large request or crash alone does not prove exploitation. An unexpected shell process warrants urgent investigation, but does not identify a specific CVE by itself.

REAL-WORLD ATTACK CASE FILES

🌍 Three major buffer overflow attacks

These historical incidents show how memory-corruption vulnerabilities affected internet infrastructure. Read the short summaries, then open the original technical references for deeper research.

2001 · Web servers

Code Red worm

Target: Microsoft IIS Indexing Service. A buffer overflow in the IDQ/IDA extension enabled remote code execution and rapid worm propagation across vulnerable web servers.

Impact: Large-scale internet disruption and website defacement.

NIST NVD: CVE-2001-0500 ↗

2003 · Database servers

SQL Slammer worm

Target: Microsoft SQL Server 2000 Resolution Service. A stack-based buffer overflow reachable over UDP 1434 allowed a small worm to spread extremely quickly.

Impact: Network congestion and service interruptions worldwide.

NIST NVD: CVE-2002-0649 ↗

2017 · Windows networks

EternalBlue / WannaCry

Target: Windows SMBv1. A remotely exploitable memory-corruption flaw in SMB handling was used by the WannaCry ransomware worm to spread between vulnerable systems.

Impact: Disruption to healthcare, business, and public services.

NIST NVD: CVE-2017-0144 ↗
