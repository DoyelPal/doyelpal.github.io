Cryptography

Explore how cryptographic techniques protect information, support secure communication, and help establish trust in digital systems. Begin with the learning objectives and fundamentals, then select a module to study each topic in more detail.

Learning Objectives

  • Explain plaintext, ciphertext, encryption, and decryption.
  • Compare symmetric and asymmetric encryption.
  • Distinguish encryption from cryptographic hashing.
  • Describe how digital signatures support integrity and authenticity.
  • Explain how cryptography supports the CIA triad.

Cryptography Fundamentals

Start with the core ideas that appear throughout the cryptography modules.

Symmetric Encryption

Uses the same shared secret key to encrypt and decrypt data. Both parties must protect the key.

Asymmetric Encryption

Uses a mathematically related public and private key pair for operations such as encryption and digital signatures.

Hashing

Maps input data to a fixed-length digest. Cryptographic hashes are commonly used to check data integrity.

Digital Signatures

Use public-key cryptography to help verify the origin and integrity of a message or document.
